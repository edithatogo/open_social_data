# Specification

## Must

Reuse existing repositories and HF destinations. Extend the existing source index
before source metadata and data. Preserve provenance, rights and four medallion
layers. Register all 22 research questions with existing/new data dependencies,
including limits on what is already available. Fail closed on uncertain rights,
missing bytes and unverified source schema. Preserve upstream attribution and
source dependence. Add offline negative tests and existing-pack validation.

## Should

Qualify coverage, source versions and a first causal-policy feasibility audit;
submit corrections upstream; use source-native immutable packets and explicit
consumer contracts rather than vendoring analytical libraries. Review the complete
HF registry before submitting metadata. Return current publication and CI evidence.

## Could

Add original-source crosschecks, a compatible economic panel and approved
publication after gates pass. Develop research protocols in the existing model
repositories and VOI methods through their supported interfaces.

## Will not in this slice

Create a repository, publish unlicensed mortality bytes, infer private records,
reconstruct suppressed cells, claim implementation effects, invent source headers,
or change existing CI/dependency/toolchain policies wholesale.
